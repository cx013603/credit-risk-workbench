# 发布范围与数据说明

这份目录是面向 GitHub 的独立展示快照。原项目的工作目录和 Git 历史未复制；只有白名单中的源码、SQL、少量配置、合成测试、依赖锁与本作品说明进入本包。

| 包含 | 排除 |
|---|---|
| 实际 Python／前端代码与 SQL | 官方 CSV、Parquet、逐笔标签与预测、真实申请明细 |
| 人工生成的虚构测试与示例 | 保存模型、运行环境、node_modules、ZIP运行介质 |
| 必要配置元数据、固定依赖版本 | SQLite应用库、申请备注、用户固定报告、备份 |
| 已有汇总指标、来源哈希、技术限制 | 账号凭据、个人邮箱、本机路径和内部聊天记录 |
| 项目目标、代码导读、运行说明 | 内部过程记录、完整交接、旧Git历史与提交身份 |

来源为 Home Credit Default Risk 数据：[来源入口](https://www.kaggle.com/competitions/home-credit-default-risk)。数据与相关材料的许可范围尚未核验；本仓库不授予数据再分发或使用许可，也未附原始数据或逐笔结果。读者如需取得原始材料，应自行查看来源平台的访问和使用条件。

本作品未擅自附加 MIT／Apache 等代码许可证。依赖组件仍遵守各自许可证；公开可阅读不等于已授予任意再利用权。发布前可由仓库所有者决定代码授权方式。

摘要中的来源哈希用于关联本机已有记录，不替代审计签名或公开可得的完整运行证据。`source-manifest.json`可验证本包精选源码的哈希；它不证明未分发模型和数据上的结果可以由本包独立重现。

仓库发布使用独立的精选目录，避免将原工作区、使用数据或历史备份整仓上传。源码中的历史版本和运行绑定保留用于阅读；旧恢复快照不代表当前应用数据。打包与发布检查清单在原工程中保留。
