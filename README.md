# 信贷风险分析平台

**从多表历史记录到可解释的申请分析工作台。** 基于公开匿名信贷数据，实现数据质量检查、SQL 特征、模型比较、统一评分和可追溯的本机分析流程。

项目覆盖 **307,511 笔带标签申请**，当前工作台统一使用 **71 项输入**；历史研究比较了逻辑回归、WOE 评分卡和树模型。新增历史特征的对照中，验证 AUC 从 **0.6761 → 0.6968**。这批验证数据参与过研究和选择，71 项方案尚无新增独立最终测试。

## 业务问题与成果

预测对象是数据集定义的还款困难事件，预测时点是当前申请时点。具体事件观察期限未披露，因此不把输出称为某个固定期限的 PD，也不用于真实银行批准／拒绝贷款。

```mermaid
flowchart LR
  A[申请与历史资料] --> B[键、类型、时间和质量检查]
  B --> C[各历史表先聚合再关联]
  C --> D[固定划分与训练内处理]
  D --> E[模型比较与阈值分析]
  E --> F[保存模型与同源评分]
  F --> G[申请分析、证据、对比与报告]
```

## 可以怎样评价结果

以下均为同一批 **46,127 笔验证申请**的已保存结果，困难事件标签有 3,724 笔；没有在本次作品整理中重新训练或评分。

| 输入与模型 | 验证 AUC ↑ | 验证 KS ↑ | 验证 Brier ↓ |
|---|---:|---:|---:|
| 40 项树模型／同预算 40 项对照 | 0.6761 | 0.2544 | 0.07172 |
| 当前 71 项树模型 | 0.6968 | 0.2946 | 0.07090 |

71 项阈值约 **7.65%**。该阈值下，困难事件识别率 **66.06%**、其他申请误报率 **36.60%**、阈值以上困难标签占比 **13.68%**。三个百分比的分母不同；AUC 也不等于准确率。详细计数、选型规则和历史测试限制见[实验说明](docs/modeling.md)。

## 快速验证一条 SQL 链路

使用 Python 3.14，安装已在原项目环境验证的依赖，然后运行：

```bash
python -m pip install -r requirements-data.txt
python examples/sql_walkthrough.py
```

示例在内存中构造 4 笔虚构申请，直接执行本项目的原聚合 SQL，展示交叉连接膨胀、先聚合再关联、未来记录排除，以及有效 0 与缺失的区别。它不训练模型，也不代表正式数据或模型效果。

纯标准库即可复算已有阈值结果的不同分母：

```bash
python examples/metrics_walkthrough.py
```

更多合成检查见[运行说明](docs/reproduction.md)。

## 技术与交付范围

Python、SQL、DuckDB、Parquet、scikit-learn；React、TypeScript、Ant Design、ECharts；FastAPI／SQLite。PySpark、独立评分 API 与基础分布监控属于历史工程扩展，当前计算为单机。

本仓库是精选的代码与研究展示快照，包含实际实现、合成检查和脱离本机路径的说明。完整本机工作台依赖原数据、保存模型及版本绑定产物，这些没有随仓库分发；克隆仓库不会自动获得一个在线评分系统。现有完整介质在原项目本机保存。[发布范围与数据说明](docs/publication-scope.md)列出了包含和排除的内容。

评估边界：申请级划分，未验证自然人互斥或时间外泛化；早期 40 项保留测试有 769 笔环境试跑暴露；新增 71 项没有独立最终测试。部署范围为本机分析，尚无真实授信收益与线上表现验证。原始数据须通过来源平台自行取得，本仓库不分发原始记录、训练产物、用户申请或本机备份；数据使用说明见[发布范围](docs/publication-scope.md)。
